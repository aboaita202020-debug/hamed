# Hamed AI Knowledge System

Hamed can ingest knowledge from multiple source classes through adapters: official documentation, books and licensed material, academic papers, public websites, news, industry reports, public datasets, GitHub repositories, user-provided files, connected apps, customer feedback, internal logs and prior agent results.

## Learning loop

1. Discover or receive a source.
2. Extract useful content.
3. Store provenance and trust level.
4. Deduplicate by content fingerprint.
5. Retrieve relevant knowledge for tasks.
6. Ask specialist/reviewer agents to verify important claims.
7. Use verified knowledge in future decisions.

Knowledge must not silently change permissions, secrets, payment rules or security policy. Copyrighted sources should be ingested only through permitted access and summarized rather than copied wholesale.
