# Hamed Learning Connectors

Hamed can be extended with connectors for lawful, accessible knowledge sources such as web search, public communities, academic indexes, books supplied by the user or licensed repositories, official documentation, GitHub, news and entrepreneur interviews/case studies.

The registry isolates source failures and records provenance. A source connector must return a title, URI and source type. Credentials belong in deployment secrets, never source code.

The learning loop is:

1. Search multiple enabled sources.
2. Collect provenance and deduplicate results.
3. Read accessible content.
4. Extract claims, lessons and actionable patterns.
5. Cross-check important claims with independent sources.
6. Build a playbook.
7. Test the playbook on an appropriate task.
8. Record outcomes and feed verified lessons back to the specialist team.

Copyrighted books and other protected content should be accessed only through lawful sources; Hamed stores derived notes and references rather than copying entire books.
