## 💡 كيفية الاستخدام

### من Dashboard:
1. افتح `HAMED_DASHBOARD.html`
2. روح على "📞 مركز المكالمات"
3. اختار التبويب المناسب:
   - **الاتصال**: لوحة اتصال
   - **السجل**: سجل المكالمات
   - **جهات الاتصال**: إدارة جهات الاتصال
   - **الإحصائيات**: إحصائيات شاملة

### من Python:
```python
from calls import CallManager

# تهيئة مدير المكالمات
manager = CallManager()

# بدء مكالمة
call = manager.initiate_call(
    client_data={
        'client_id': 'client_123',
        'name': 'أحمد محمد',
        'phone': '01012345678',
        'website': 'example.com',
        'score': 65
    },
    call_type='sales',
    purpose='عرض خدمة تحليل المواقع'
)

print(f"Call ID: {call['call_id']}")
print(f"Script: {call['script']}")

# بدء المكالمة فعلياً
manager.start_call(call['call_id'])

# إنهاء المكالمة
result = manager.end_call(
    call_id=call['call_id'],
    duration=320,
    outcome='success',
    notes='العميل مهتم، سيتم إرسال عرض سعر'
)

# الحصول على الإحصائيات
stats = manager.get_stats(days=7)
print(f"Total calls: {stats['overall']['total_calls']}")
print(f"Success rate: {stats['overall']['success_rate']}%")
```
