🚀 تشغيل بوت تيليجرام

الخطوة 1: افتح CMD في مجلد المشروع

اضغط على الزر ده هي نسخ الأمر ليك:

cd path/to/hamed-ai/freelance_automation

الخطوة 2: ثبّت المكتبات

اضغط على الزر ده هي نسخ الأمر ليك:

pip install python-dotenv requests python-telegram-bot

الخطوة 3: شغّل البوت

اضغط على الزر ده هي نسخ الأمر ليك:

python bots/telegram_bot.py

الخطوة 4: جرب البوت في تيليجرام

اضغط على الزر ده هيفتح البوت في تيليجرام:

📱 افتح البوت في تيليجرام
