🚀 ارفع المشروع على GitHub

خطوات بسيطة جداً - من غير تعقيد

1 اعمل Repository على GitHub

اضغط على الزر ده هيفتح صفحة إنشاء Repository:

🌐 افتح صفحة إنشاء Repository

املأ البيانات زي كده:

  • ✅ Repository name: hamed-ai
  • ✅ Description: Hamed AI - Complete Business Operating System
  • ✅ Public (اختار Public)
  • ✅ Add a README (علّم عليه)
  • ✅ اضغط Create repository

2 حمّل المشروع

بما إن المشروع هنا، هتحتاج تنزله:

الطريقة الأسهل:

  1. افتح GitHub Desktop (لو مش مثبت، حمّله من هنا)
  2. اضغط File → Add Local Repository
  3. اختار مجلد المشروع
  4. اضغط Publish repository

أو من CMD (لو عايز):

cd path/to/project && git init && git add . && git commit -m "Initial commit" && git remote add origin https://github.com/YOUR-USERNAME/hamed-ai.git && git push -u origin main

3 فعّل GitHub Pages (عشان الداشبورد يشتغل)

بعد ما ترفع المشروع، فعّل GitHub Pages:

  1. روح على الـ Repository في GitHub
  2. اضغط Settings (إعدادات)
  3. من القائمة الجانبية، اضغط Pages
  4. في Source اختار:
    • • Branch: main
    • • Folder: / (root)
  5. اضغط Save
  6. استنى 1-2 دقيقة

✅ الداشبورد هيكون متاح على:

https://YOUR-USERNAME.github.io/hamed-ai/dashboard.html
